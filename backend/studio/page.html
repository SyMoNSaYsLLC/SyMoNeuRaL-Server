What the bench is, and what queueing from inside it does

ComfyUI's node editor, served from this origin at /studio/editor/ — its editor, not a copy of it: snap-to-grid, typed links, the node search palette and the release-a-wire suggestions are all upstream's and are better than a hand-written canvas would have been. Queueing from inside it takes the same GPU lease the agent does; a render started here cannot lock out chat or training. Because this card is single and contended, a render queued here will evict whatever surface is resident — chat included — and wait for the drain before it starts.

Agent

A local model with the tool list below. It calls a tool, reads the raw result, and calls another until it can answer — every step is streamed here as it happens, including the arguments it chose and what came back. Nothing is summarised on the way through.

Render

The stock FLUX.1-schnell graph, run through the GPU governor: the card is acquired for the job, released when it finishes, and the drain is waited for rather than assumed. Four steps at cfg 1.0 is the design point of this model, not a shortcut.

Tools the agent can call

Generated from the running registry, not maintained by hand — the same list is rendered into the model's system prompt, so this page cannot show a tool the model does not have. Rows marked writes change the host.
