# `frontend/site/pages/` — the HTML

One file per page. **Published flat to the webroot**: `pages/chat.html` is served at
`/chat.html`, while `css/`, `js/` and `assets/` keep their directories, because every page
links `/js/app.js` absolutely.

Most are generated by `tools/build/build_pages.py`. Edit the generator, not the output —
the next regeneration discards a hand edit, silently.

```bash
python3 tools/build/build_pages.py        # then run it AGAIN and diff
python3 tools/build/build_cachebust.py    # stamp the ?v= query strings
sudo scripts/deploy.sh
```

An unstamped asset is cacheable for a week against markup that changed, which is how a page
ships new HTML against last week's JavaScript.

`deploy.sh` **refuses when it matches no pages here.** Before that check existed it printed
`staged: (0 files)` and then `deployed`, and had been publishing nothing since the site was
restructured.
