            How this reaches the box, and why it is not on /api
            
        
              
        The prefix is the whole safety case.
                ops/Caddyfile hands the entire /api/* subtree to the public
                internet, and the module behind this page reads arbitrary workspace files and executes
                subprocesses. An /api/coder/… endpoint would be remote file read on a
                public host the instant it existed, so there is not one and there must never be one. The
                reads here are at /local/coder/*, which matches no handle block
                in that config: it falls through to the static file server, is looked up in
                /var/www/symoneural, and 404s off disk without this process ever being
                asked.
        
              
        Two locks, not one. The API does not
                trust that config file either. Every route here goes through a guard that reads the socket
                peer and refuses the request outright if any X-Forwarded-* header is present
                — which is exactly what a future handle /local* block would produce. Add
                one a year from now and these routes go dead rather than public.
        
              
        The token never comes here. The
                module’s token exists to stop a caller who reached it over a network, and these routes
                are already past a stricter test than that. The alternative is a browser page that holds the
                credential, which means the token in a URL, in localStorage, or committed into
                this repository’s own HTML — and a credential that has been displayed is spent. It
                is read inside the server process, used there, and never sent to this page.
        
              
        A refused file is shown, not hidden. The
                listing flags entries the denylist covers instead of omitting them. A tree that quietly
                dropped training/corpus.jsonl would be showing you something that is not what is
                on the disk — the decorative dishonesty this site exists to argue against — and it
                would also teach an operator that there is no denylist, so the first time they wondered where
                a file went they would go looking for a bug instead of a rule.
