Procedure, not state. A guide that names a current fact **dates it and says how it was
measured**, or it does not name it. This is where a figure gets carried forward and re-dated
if nobody is watching.

`playbook-00-index.md` first.

The CUDA curriculum is reference material for the engine and kernel work under
`backend/studio/plugins/reinforce/symoneural/compute/`, which is hand-written CUDA C++
compiled at runtime by NVRTC — not a wrapper over a third-party runtime.
