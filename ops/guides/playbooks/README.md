# `ops/guides/playbooks/` — eleven numbered procedures

Start at [`playbook-00-index.md`](playbook-00-index.md).

**Procedure, not state.** A playbook that names a current fact dates it and says how it was
measured, or it does not name it — this is exactly where a figure gets carried forward and
re-dated, which is the failure this repository warns about most.

A step that cannot be run as written is a bug in the playbook. Fix the step; do not work
around it and leave the next person the same wall.
